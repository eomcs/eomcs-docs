# 비개발자를 위한 바이브 코딩 — 교육 커리큘럼

이 과정에서는 AI 코딩 에이전트를 활용하여 프로그램을 작성하고, 이를 통해 업무 자동화 도구를 만드는 방법을 학습한다. 수강생은 코드를 직접 작성하지 않고, AI에게 요청하고 검증하는 과정을 반복하며 실습을 진행한다. 1부에서는 바이브 코딩의 기본 원리와 흐름을 익히고, 2부에서는 실제 업무 자동화 프로그램을 구현한다.

## 1. 교육 개요

| 항목 | 내용 |
|---|---|
| 교육 대상 | 코딩 경험이 없는 비개발자 (사무직, 기획·마케팅·운영 등 실무자) |
| 총 교육 시간 | 40시간 (하루 8시간 × 5일) |
| 시간 기준 | 1교시 = 50분 수업 + 10분 휴식, 하루 8교시 |
| 과정 구성 | 1부 바이브 코딩 기본 (16시간, 1~2일차) / 2부 바이브 코딩으로 업무 자동화 프로그래밍 (24시간, 3~5일차) |
| 교육 방향 | 1부에서는 특정 업무와 관계없이 AI와 함께 프로그램을 만드는 방법을 익히고, 2부에서는 이를 파일·데이터 등 업무 자동화에 적용한다. |

### 수료 목표

교육을 마치면 수강생은 다음을 할 수 있다.

1. 만들고 싶은 프로그램을 AI 코딩 에이전트가 이해할 수 있는 **요구사항(스펙)** 으로 정리할 수 있다.
2. AI 코딩 에이전트에게 요청하고, 결과를 **실행·검증·수정**하는 반복 작업 흐름을 혼자 수행할 수 있다.
3. 오류 메시지를 읽고 AI와 함께 **원인을 찾아 해결**할 수 있다.
4. 파일·폴더, 엑셀·CSV, 문서(PDF/Word), 웹 데이터, 이메일 등 **반복 업무를 자동화하는 프로그램**을 만들 수 있다.
5. 만든 프로그램을 **정해진 시간에 자동 실행**하고, 동료가 쓸 수 있도록 **정리·공유**할 수 있다.

### 교육 환경

| 구분 | 내용 |
|---|---|
| 언어 | Python (문법을 가르치는 과정이 아니라, AI가 만든 코드를 "읽고 판단"하는 수준으로만 다룬다) |
| 편집기 | VS Code |
| AI 코딩 에이전트 | VS Code + (OpenAI Codex 또는 Claude Code) |
| 보조 도구 | 터미널(기본 명령 몇 가지), Git(저장/되돌리기 수준) |
| 실습 데이터 | 강사가 제공하는 샘플 엑셀·CSV·텍스트·PDF 파일 (실제 업무 데이터와 유사한 형태) |
| 준비 사항 | 수강생 1인당 노트북 1대, AI 코딩 에이전트 계정 또는 API 키, 인터넷 |

### 교육 원칙

- **코드를 외우지 않는다.** 코드는 AI가 쓰고, 사람은 "무엇을 만들지"와 "제대로 만들어졌는지"를 책임진다.
- **매 교시 손으로 만든다.** 모든 교시는 설명 15분 내외 + 실습 35분 내외로 구성한다.
- **작게 만들고 자주 확인한다.** 한 번에 큰 프로그램을 요청하지 않고, 단계별로 요청하고 즉시 실행해 본다.
- **AI의 결과를 믿지 않고 검증한다.** 샘플 데이터로 결과를 확인하는 습관을 1일차부터 들인다.

## 3. 1부 — 바이브 코딩 기본 (16시간)

### 과정 소개

1부는 특정 업무와 관계없이 "AI와 함께 프로그램을 만드는 방법" 자체를 익히는 과정이다. 코드 문법을 배우는 대신, 만들고 싶은 것을 요구사항으로 정리하고, AI 코딩 에이전트에게 요청하고, 결과를 실행해 확인하고, 오류를 함께 고치는 흐름을 2일 동안 반복해서 몸에 익힌다. 1일차에는 환경을 준비하고 작은 프로그램을 만들어 보며 요청·수정·오류 해결의 기본 흐름을 경험하고, 2일차에는 큰 요구를 쪼개어 단계별로 만들고 검증·저장하는 방법과 스펙 문서 작성법을 익혀 미니 프로젝트를 완성한다.

**과정 목표**

- AI 코딩 에이전트의 역할과 한계를 이해하고, 사람이 맡아야 할 일(무엇을 만들지 정하기, 결과 검증하기)을 구분한다.
- 요청 → 생성 → 실행 → 확인 → 수정의 반복 흐름을 도구 도움 없이 혼자 수행한다.
- 큰 프로그램을 작은 단계로 나누어 요청하고, 단계마다 검증하고 저장하는 습관을 들인다.
- 만들고 싶은 프로그램을 스펙 문서로 정리해 AI 에이전트에게 전달한다.

**이 과정을 마치면**

- 코딩 경험이 없어도 생활 속 작은 도구(계산기, 기록 관리, 추첨기 등)를 AI와 함께 만들고 실행할 수 있다.
- 오류 메시지를 두려워하지 않고, AI에게 전달해 원인을 찾고 고칠 수 있다.
- 작업 상태를 저장하고 잘못되면 이전 상태로 되돌릴 수 있다.
- 스펙 문서와 단계별 구현 결과, 사용 설명서(README)를 갖춘 미니 프로젝트 1개를 가지게 된다.
- 2부에서 업무 자동화 프로그램을 만들 때 필요한 작업 흐름을 모두 갖추게 된다.

### 1일차: 바이브 코딩 시작하기

| 교시 | 주제 | 학습 목표 | 주요 내용 |
|---|---|---|---|
| 1 | 오리엔테이션 & 바이브 코딩이란 | 프로그램과 AI 코딩 에이전트의 역할을 설명할 수 있다 | - 프로그램이란: 입력 → 처리 → 출력<br>- 바이브 코딩: 사람이 "무엇을", AI가 "어떻게"<br>- AI 코딩 에이전트가 할 수 있는 것 / 없는 것<br>- 5일 과정 소개, 수료 목표 |
| 2 | 개발 환경 준비 | 실습 환경을 스스로 구성할 수 있다 | - Python, VS Code 설치<br>- AI 코딩 에이전트 설치·로그인<br>- 작업 폴더 만들기와 VS Code로 열기<br>- 터미널 창 열기, 폴더 이동 |
| 3 | 첫 프로그램 만들기 | 요청 → 생성 → 실행 → 확인 흐름을 수행할 수 있다 | - AI에게 프로그램 요청하기<br>- 생성된 파일 확인하기<br>- 터미널에서 실행하기<br>- 결과 확인하고 다시 요청하기 |
| 4 | 프로그램 읽기 | AI가 만든 코드의 큰 구조를 읽고 설명할 수 있다 | - 코드를 "읽는" 수준의 최소 개념: 변수, 입력/출력, 조건, 반복, 함수<br>- 코드가 무슨 일을 하는지 AI에게 설명 요청하기<br>- 주석의 역할 |

| 7 | 오류 다루기 | 오류 메시지를 읽고 AI와 함께 해결할 수 있다 | - 오류의 종류: 실행 안 됨 / 실행은 되는데 결과가 틀림<br>- 오류 메시지 복사해서 AI에게 넘기기<br>- 문제 재현 방법 설명하기<br>- "고쳤다"는 말을 믿지 말고 다시 실행해서 확인 |

## 4. 2부 — 바이브 코딩으로 업무 자동화 프로그래밍 (24시간)

### 과정 소개

2부는 1부에서 익힌 바이브 코딩 흐름을 실제 업무 자동화에 적용하는 과정이다. 파일·폴더 정리, 엑셀·CSV 가공, Word·PDF 문서 생성, 웹·공공데이터 수집, 이메일 발송, 정해진 시간에 자동 실행하기까지 사무 업무에서 반복되는 작업을 하나씩 자동화해 본다. 3일차에는 파일과 엑셀을, 4일차에는 문서·웹·이메일과 자동 실행을 다루며 매일 하나의 자동화 프로그램을 완성하고, 5일차에는 만든 프로그램을 동료도 쓸 수 있게 다듬는 방법을 익힌 뒤 각자의 실제 업무를 자동화하는 종합 프로젝트를 수행한다.

**과정 목표**

- 내 업무에서 자동화할 수 있는 반복 작업을 골라내고, 자동화 전후의 흐름을 스펙으로 정리한다.
- 파일, 엑셀·CSV, 문서, 웹 데이터, 이메일 등 업무 데이터를 다루는 자동화 프로그램을 AI와 함께 만든다.
- 수집 → 가공 → 보고서 → 발송으로 이어지는 여러 단계를 하나의 프로그램으로 연결하고, 정해진 시간에 자동 실행되게 한다.
- 오류 처리, 설정 분리, 비밀 정보 관리, 원본 데이터 보호 등 사람 없이 돌아가는 프로그램에 필요한 안전장치를 갖춘다.
- 만든 프로그램을 화면을 붙이거나 실행 파일로 만들어 동료에게 전달한다.

**이 과정을 마치면**

- 여러 엑셀 파일을 합쳐 집계 보고서를 만드는 일, 명단으로 문서를 대량 생성하는 일, 웹이나 공공데이터에서 자료를 받아 정리하는 일을 프로그램에 맡길 수 있다.
- 매일 아침 자동으로 데이터를 수집·가공해 보고서를 메일로 보내는 파이프라인을 직접 구성할 수 있다.
- 자동화 프로그램이 실패했을 때 원인을 찾고, 다음에는 실패하지 않도록 안전장치를 추가할 수 있다.
- 동료가 바로 쓸 수 있는 형태(간단한 화면, 실행 파일, 사용 설명서)로 프로그램을 공유할 수 있다.
- 자신의 실제 업무를 자동화한 종합 프로젝트 결과물과, 다음 자동화 대상을 스스로 고를 수 있는 안목을 가지게 된다.

### 3일차: 파일·엑셀 자동화

| 교시 | 주제 | 학습 목표 | 주요 내용 |
|---|---|---|---|
| 1 | 업무 자동화 개요 & 자동화 대상 찾기 | 내 업무에서 자동화할 수 있는 작업을 골라낼 수 있다 | - 자동화하기 좋은 일의 특징: 반복, 규칙, 파일 기반<br>- 자동화하기 어려운 일: 판단, 예외 많음<br>- 반복 작업 목록(인벤토리) 작성법<br>- 자동화 전/후 비교: 시간, 실수 |
| 2 | 파일·폴더 자동화 | 파일 이름 변경, 분류, 이동, 백업을 자동화할 수 있다 | - 파일·폴더를 다루는 프로그램의 기본 (경로, 확장자)<br>- 일괄 이름 변경, 날짜별·유형별 분류<br>- 백업 복사와 오래된 파일 정리<br>- **실수 방지:** 삭제 대신 이동, 실행 전 미리보기(dry-run) |
| 3 | 텍스트 파일 처리 | 텍스트 파일에서 원하는 내용을 찾고 바꾸고 요약 파일을 만들 수 있다 | - 텍스트 파일 읽기/쓰기<br>- 특정 단어·패턴 찾기, 일괄 치환<br>- 여러 파일에서 정보 추출해 하나의 보고서로<br>- 인코딩(한글 깨짐) 문제 대처 |
| 4 | 엑셀 자동화 ① 읽기와 합치기 | 여러 엑셀 파일을 읽어 하나로 합칠 수 있다 | - 엑셀 파일을 프로그램이 다루는 방식 (시트, 행, 열)<br>- 라이브러리 선택: openpyxl / pandas (AI가 고르게 하되 차이 이해)<br>- 여러 파일·시트 합치기<br>- 헤더가 다르거나 빈 행이 있을 때 |
| 5 | 엑셀 자동화 ② 가공과 쓰기 | 합친 데이터를 집계하고 서식 있는 엑셀로 저장할 수 있다 | - 합계·평균·그룹별 집계, 정렬, 필터<br>- 새 시트에 결과 쓰기<br>- 서식 지정: 열 너비, 숫자 형식, 강조<br>- 결과를 엑셀로 열어 검증하는 습관 |
| 6 | CSV와 데이터 정리 | 지저분한 데이터를 정리된 표로 만들 수 있다 | - CSV와 엑셀의 차이<br>- 중복 제거, 공백·형식 통일(날짜, 전화번호, 금액)<br>- 빈 값 처리, 잘못된 값 찾기<br>- 정리 전/후 건수 비교로 검증 |
| 7 | 실습: 엑셀 통합 보고서 자동화 ① | 스펙 작성부터 구현까지 자동화 프로그램을 혼자 만들 수 있다 | - 과제: "매월 지점별 매출 파일을 받아 통합 보고서 엑셀을 만드는 프로그램"<br>- 스펙 작성 → 기능 쪼개기 → 단계별 구현 |
| 8 | 실습: 엑셀 통합 보고서 자동화 ② & 3일차 정리 | 결과를 검증하고 다음 달에도 쓸 수 있게 정리할 수 있다 | - 나머지 단계 구현<br>- 다른 달 데이터로 재실행해 검증<br>- 폴더 경로·파일명이 바뀌어도 되게 만들기<br>- 3일차 정리 |

### 4일차: 문서·웹·이메일 자동화와 자동 실행

| 교시 | 주제 | 학습 목표 | 주요 내용 |
|---|---|---|---|
| 1 | 문서 자동화 — Word·PDF | 템플릿 기반 문서 생성과 PDF 처리를 자동화할 수 있다 | - 템플릿(Word)에 데이터 채워 문서 대량 생성<br>- PDF 합치기·나누기·텍스트 추출<br>- 엑셀 명단 → 개인별 안내문 PDF |
| 2 | 데이터 시각화 | 데이터를 차트로 만들어 보고서에 넣을 수 있다 | - 차트 종류 고르기: 추이는 선, 비교는 막대<br>- 차트 이미지 생성·저장<br>- 차트를 엑셀·Word·PDF 보고서에 넣기<br>- 한글 폰트 깨짐 대처 |
| 3 | 웹에서 데이터 가져오기 ① 웹 페이지 | 웹 페이지의 정보를 수집해 표로 저장할 수 있다 | - 웹 스크래핑의 원리 (페이지 구조)<br>- 원하는 항목 지정해 수집 요청하기<br>- 수집 결과를 엑셀/CSV로 저장<br>- **주의사항:** 이용 약관, 과도한 요청 금지, 로그인 페이지, 개인정보 |
| 4 | 웹에서 데이터 가져오기 ② 공공데이터·API | API로 데이터를 받아 활용할 수 있다 | - API: 프로그램끼리 데이터를 주고받는 창구<br>- 공공데이터포털 키 발급과 사용<br>- JSON 형식 읽기 (구조만 이해)<br>- API 키 관리: 코드에 직접 쓰지 않기 |
| 5 | 이메일·메신저 자동화 | 결과 파일을 자동으로 발송하고 알림을 보낼 수 있다 | - 이메일 자동 발송 (SMTP 설정, 앱 비밀번호)<br>- 수신자 목록 기반 개인화 발송, 첨부파일<br>- 메신저 알림 (Slack/카카오워크/Teams 웹훅 중 환경에 맞게)<br>- 발송 전 테스트 모드 (나에게만 보내기) |
| 6 | 자동 실행 — 스케줄링 | 프로그램을 정해진 시간에 자동 실행되게 할 수 있다 | - Windows 작업 스케줄러 / macOS·Linux cron<br>- 자동 실행 시 자주 생기는 문제: 경로, 가상환경, 권한<br>- 실행 기록(로그) 남기기와 실패 알림<br>- 사람 없이 돌아가는 프로그램의 안전장치 |
| 7 | 실습: 자동화 파이프라인 ① | 수집·가공·보고·발송을 하나의 프로그램으로 연결할 수 있다 | - 과제: "데이터 수집(웹/API 또는 파일) → 정리·집계 → 차트 포함 보고서 → 메일 발송 → 매일 자동 실행"<br>- 스펙 작성, 단계 분리, 각 단계 독립 검증 |
| 8 | 실습: 자동화 파이프라인 ② & 4일차 정리 | 파이프라인을 완성하고 실패 상황에 대비할 수 있다 | - 보고서·발송 단계 구현<br>- 일부러 실패시키기(파일 없음, 네트워크 오류)와 대응<br>- 4일차 정리, 종합 프로젝트 주제 확정 |
