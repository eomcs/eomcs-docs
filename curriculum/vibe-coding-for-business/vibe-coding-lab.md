# 비개발자를 위한 바이브 코딩 — 교시별 실습

[curriculum.md](curriculum.md)의 각 교시에 대응하는 실습 내용이다. 모든 교시는 설명 15분 내외 + 실습 35분 내외로 진행하며, 실습 시간은 아래 내용을 기준으로 한다.

## 1부 바이브 코딩 기본

### 1일차: 바이브 코딩 시작하기

| 교시 | 주제 | 실습 |
|---|---|---|
| 1 | 오리엔테이션 & 바이브 코딩이란 | 강사 시연: 요청 한 줄로 프로그램이 만들어지고 실행되는 과정 관찰 |
| 2 | 개발 환경 준비 | 환경 설치 완료 후 `python --version` 확인, AI 에이전트에 첫 인사 |
| 3 | 첫 프로그램 만들기 | "이름을 입력하면 인사하는 프로그램", "두 숫자를 더하는 프로그램" 만들고 실행 |
| 4 | 프로그램 읽기 | AI에게 "이 코드를 한 줄씩 쉽게 설명해줘" 요청, 동료에게 코드 흐름 설명하기 |
| 5 | 요청(프롬프트) 잘 쓰기 | "단위 변환기"를 요청 수준별로 3번 만들어 결과 비교 |
| 6 | 수정·개선 요청하기 | 5교시 프로그램에 기능 3개를 순서대로 추가 (예: 변환 종류 추가, 반복 실행, 결과 저장) |
| 7 | 오류 다루기 | 강사가 준비한 오류 있는 프로그램 5개를 AI와 함께 고치기 |
| 8 | 실습: 나만의 첫 프로그램 & 1일차 정리 | 개인 실습 35분 + 결과 공유 10분 |

### 2일차: 제대로 만들기

| 교시 | 주제 | 실습 |
|---|---|---|
| 1 | 프로그램 쪼개서 만들기 | "가계부 프로그램"을 기능 목록 5개로 쪼개 단계별로 구현 |
| 2 | 검증하기 — AI 결과 확인 | 1교시 가계부 프로그램에 검증 사례 만들고 테스트 코드 생성·실행 |
| 3 | 저장과 되돌리기 — Git 입문 | 가계부 프로젝트를 Git으로 저장 → 일부러 망가뜨리기 → 되돌리기 |
| 4 | 작업 명세서(스펙) 작성하기 | 미니 프로젝트 주제 선정 후 스펙 문서 작성 (강사 템플릿 제공) |
| 5 | 외부 라이브러리 활용 | 스펙에 필요한 라이브러리를 AI와 함께 고르고 설치 (예: 날짜 처리, 표 출력, 엑셀) |
| 6 | 미니 프로젝트 ① 구현 | 개인 미니 프로젝트 구현 (예: 할 일 관리, 가계부, 공부 시간 기록, 독서 기록) |
| 7 | 미니 프로젝트 ② 완성 | 미니 프로젝트 마무리, README 작성, 최종 저장 |
| 8 | 발표·공유 & 1부 정리 | 발표 (1인 2~3분) 및 피드백 |

## 2부 업무 자동화 프로그래밍

### 3일차: 파일·엑셀 자동화

| 교시 | 주제 | 실습 |
|---|---|---|
| 1 | 업무 자동화 개요 & 자동화 대상 찾기 | 개인 반복 업무 인벤토리 작성 → 2부 종합 프로젝트 후보 선정 |
| 2 | 파일·폴더 자동화 | 뒤죽박죽 폴더(샘플 200개 파일)를 규칙에 따라 정리하는 프로그램 |
| 3 | 텍스트 파일 처리 | 로그/메모 파일 수십 개에서 키워드 추출 후 요약 파일 생성 |
| 4 | 엑셀 자동화 ① 읽기와 합치기 | 월별 매출 엑셀 12개를 하나로 합치기 |
| 5 | 엑셀 자동화 ② 가공과 쓰기 | 4교시 데이터로 지점별·월별 집계 시트 생성 |
| 6 | CSV와 데이터 정리 | 고객 명단 CSV(샘플) 정리 → 깨끗한 엑셀로 저장 |
| 7 | 실습: 엑셀 통합 보고서 자동화 ① | 스펙 작성 및 1~2단계 구현 |
| 8 | 실습: 엑셀 통합 보고서 자동화 ② & 3일차 정리 | 완성 후 Git 저장, 결과 공유 |

### 4일차: 문서·웹·이메일 자동화와 자동 실행

| 교시 | 주제 | 실습 |
|---|---|---|
| 1 | 문서 자동화 — Word·PDF | 참가자 명단 엑셀로 수료증/안내문 50장 자동 생성 |
| 2 | 데이터 시각화 | 3일차 매출 데이터로 월별 추이·지점 비교 차트 생성, 보고서 삽입 |
| 3 | 웹에서 데이터 가져오기 ① 웹 페이지 | 공개 게시판/뉴스 목록 수집해 엑셀 저장 |
| 4 | 웹에서 데이터 가져오기 ② 공공데이터·API | 공공데이터(날씨, 환율, 지역 통계 등) 받아 엑셀 저장 |
| 5 | 이메일·메신저 자동화 | 엑셀 명단 대상 개인별 보고서 첨부 메일 발송 (테스트 모드) |
| 6 | 자동 실행 — 스케줄링 | 3일차 보고서 프로그램을 매일 아침 자동 실행 등록, 로그 확인 |
| 7 | 실습: 자동화 파이프라인 ① | 스펙 작성 및 수집·가공 단계 구현 |
| 8 | 실습: 자동화 파이프라인 ② & 4일차 정리 | 완성, Git 저장, 종합 프로젝트 주제 제출 |
