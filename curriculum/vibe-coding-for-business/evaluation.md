# 비개발자를 위한 바이브 코딩 — 평가

[curriculum.md](curriculum.md) 과정의 평가 기준이다. 실습 과제의 세부 내용은 [vibe-coding-lab.md](vibe-coding-lab.md)를 참조한다.

## 평가 방법

| 구분 | 비중 | 내용 |
|---|---|---|
| 1부 미니 프로젝트 | 30% | 스펙 문서, 단계별 구현 여부, 검증 사례, README |
| 3·4일차 실습 과제 | 30% | 엑셀 통합 보고서, 자동화 파이프라인의 완성도와 재실행 가능 여부 |
| 종합 프로젝트 | 40% | 업무 적합성, 스펙 품질, 동작 검증, 예외 처리, 발표 |

평가 기준은 "코드를 얼마나 아는가"가 아니라 **"혼자서 스펙을 쓰고, 만들고, 검증하고, 고칠 수 있는가"** 에 둔다.
